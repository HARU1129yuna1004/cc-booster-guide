1-4. AI秘書の家（プロジェクト）を作る

Codex は、あなたが指定したフォルダの中だけで作業します。Codex では、そのフォルダのことを「プロジェクト」と呼びます。

先に、AI秘書が住む家を作ります。まだ中身は入れません。空のままで大丈夫です。

  1. Finder を開いて、Cmd + Shift + H を押します。あなたの名前のフォルダ（ホーム）が開きます。
  2. Cmd + Shift + N で新しいフォルダを作り、名前を ai にして Enter を押します。
  3. 作った ai を開いて、その中にもう1つ mycompany というフォルダを作ります。

これで ~/ai/mycompany ができました。

⚠️ 「書類」や「デスクトップ」の中には作らないでください

Mac の「書類」と「デスクトップ」は、iCloud に自動で同期されることがあります。

同期されると、パソコンの空きが減ったときに中身だけ雲の向こうへ退避されます。見た目はファイルがあるのに、AIが開こうとすると読めない、という状態になります。

ホームの直下（いま作った ai）なら、それが起きません。

作ったフォルダを、Codex に「プロジェクト」として教えます。

  1. 入力欄のすぐ上にある 🗀 プロジェクトを選択 を押します。

    入力欄には「何でもどうぞ」と薄い字が出ています。その1つ上の帯です。

  2. 小さい窓が開きます。いちばん下の ＋ 新しいプロジェクト を押します。
  3. いま作った ~/ai/mycompany を選びます。
  4. 画面のまん中の見出しが「mycompanyでは何に取り組みますか？」のようにフォルダの名前に変われば成功です。

💡 ここが目印になります

プロジェクトを選ぶ前は「何を作りましょうか？」。

選んだあとは「（フォルダの名前）では何に取り組みますか？」。

この見出しが変わっていないときは、まだ選べていません。ここだけ見ていれば迷いません。

👉 一度選んだプロジェクトを、あとから切り替えたい人だけ開く押して開く

同じ場所から切り替えられます。

  1. 入力欄の上の帯（いまのプロジェクト名が出ています）を押します。
  2. 一覧から選び直すか、＋ 新しいプロジェクト で足します。

上の検索欄に名前を打つと、たくさんある人でもすぐ見つかります。

1-6. 「やっていい？」の聞かれかたを知っておく

💡 Codex は、先に聞かずに、あとから取り消せるようにします

僕が自分のパソコンで試したところ、プロジェクトのフォルダの中にファイルを作るときは、確認の窓は出ませんでした。作ったあとに、こういう帯が出ます。

test.txt を編集しました　+1 -0　　元に戻す ↩　　レビューする

「作りました。気に入らなければ戻せます」と言っています。

やり直したいときは 元に戻す。中身を見たいときは レビューする です。

先に止められないぶん、この帯が味見のタイミングになります。

⚠️ ただし、窓が出ることもあります

フォルダの外に出ようとしたとき、インターネットにつなごうとしたとき、.git・.agents・.codex という3つの決まった名前のフォルダを触ろうとしたときは、確認を求められます。

そのときは「許可する」側を押してください。この手順書では、出てくる場所ごとにどれを押すか書いてあります。

確認をどれくらい出すかは、入力欄の下の ✋ 承認を依頼 のところで切り替わります。初期設定のままだとどう出るかは、僕は確かめられていません。窓が出た人は、落ち着いて許可する側を押してください。

👉 .claude というフォルダが見えない人だけ開く押して開く

大丈夫です。消えていません。Finder が隠しているだけです。

名前が「.」で始まるフォルダは、Finder では最初から見えません。Cmd + Shift + .（コマンド＋シフト＋ピリオド）を押すと見えます。もう一度押すと、また隠れます。

見えていなくても、ちゃんとコピーされています。この先、あなたがこのフォルダを開く用事はほとんどありません。Codex が中を見るだけです。

👉 ダウンロードが途中で止まった・広げられなかった人だけ開く押して開く

大丈夫です。もう一度やれば、たいてい通ります。約16MBあるので、回線が細いと途中で切れます。

  1. 落ちてきたファイルの大きさが16MBくらいあるか見てください。極端に小さければ失敗しています。
  2. 広げたのに CLAUDE.md が出てこないときは、圧縮ファイルが壊れています。落としたファイルを捨てて、最初からやり直してください。

2-2. 先に、書き込みができる状態か確かめます

🛑 ここを飛ばすと、次の 2-3 が失敗します

Codex には「読むだけ」と「書いてもいい」の2つの状態があります。

そして公式の説明によると、ふつうに作ったフォルダは「読むだけ」で始まることがあります。（正確には、git という道具で管理されていないフォルダが対象です。この手順書のとおりに作ったフォルダは、これに当てはまります。）

読むだけの状態のままだと、次の 2-3 でファイルが作れず、そこで止まります。先に1回だけ確かめておきます。30秒で終わります。

これを送ると何が起きるか：作れた場合：「作りました」と出て、test.txt を編集しました の帯が出ます。そのまま 2-3 へ進んでください。
作れなかった場合：「読み取り専用です」「権限がありません」のような答えが返ります。下の折りたたみを開いてください。

👉 作れなかった人だけ開く（ここを直せば先へ進めます）押して開く

大丈夫です。壊れていません。「読むだけ」で始まっただけです。

やり方その1：入力欄の下で切り替える

  1. 入力欄の下の ✋ 承認を依頼 を押します。
  2. 「読み取り専用」ではなく、書き込みができる側を選びます。表示は「承認を依頼」「Auto」など、版によって変わります。ぜんぶ自由にやっていい設定（フルアクセス）は選ばないでください。
  3. もう一度、上のお願い文を送ります。

やり方その2：フォルダを git で管理してもらう

それでもダメなときは、Codex に下の1行を送ってください。git で管理されたフォルダなら、最初から書ける状態で始まります。

git で管理できるようにしたあとは、Codex アプリを一度閉じて、開き直してください。Codex は始めるときに1回だけ「このフォルダは書いていいか」を判断します。開き直さないと、切り替わりません。ここを忘れる人がとても多いところです。

git が入っていないと言われたら、その旨をそのまま僕に教えてください。相談先は第5章のいちばん下です。

確かめ終わったら、test.txt は消してしまってかまいません。残っていても害はありません。

2-3. ★ここが一番大事★ AGENTS.md を作ってもらう

⚠️ ここだけ気をつけて

Codex は CLAUDE.md を1文字も読みません。読むのは AGENTS.md という名前のファイルだけです。

しかも、読めなかったと文句も言いません。黙って無視します。「入れたのに、ぜんぜん秘書っぽくならない」の原因は、ほぼこれです。

料理でたとえます。レシピは同じなのに、CLAUDE.md という表紙の紙は、この厨房では誰も手に取らない。AGENTS.md という表紙の紙だけが読まれる。だから表紙を付け替えます。

🍀 この作業、Codex にやってもらえます
