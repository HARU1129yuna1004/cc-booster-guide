1-5. AI秘書の家（フォルダ）を作る

Claude Code は、あなたが選んだフォルダの中だけで作業します。先に、その家を作ります。まだ中身は入れません。空のままで大丈夫です。

  1. Finder を開いて、Cmd + Shift + H を押します。あなたの名前のフォルダ（ホーム）が開きます。
  2. Cmd + Shift + N で新しいフォルダを作り、名前を ai にして Enter を押します。
  3. 作った ai を開いて、その中にもう1つ mycompany というフォルダを作ります。

これで ~/ai/mycompany ができました。中身はまだ空です。次に中身を入れます。

⚠️ 「書類」や「デスクトップ」の中には作らないでください

Mac の「書類」と「デスクトップ」は、iCloud に自動で同期されることがあります。

同期されると、パソコンの空きが減ったときに中身だけ雲の向こうへ退避されます。見た目はファイルがあるのに、AIが開こうとすると読めない、という状態になります。

ホームの直下（いま作った ai）なら、それが起きません。

👉 すでに「書類」の中に作ってしまった人だけ開く押して開く

大丈夫です。フォルダごと引っ越せば直ります。

  1. Finder で Cmd + Shift + H を押してホームを開きます。
  2. そこに ai フォルダを作ります。
  3. 「書類」の mycompany を、その中へドラッグして移します。
  4. Claude で、もう一度 Select folder から新しい場所を選び直します。

ファイルの名前に雲のマークが付いていたら、それが退避された状態です。一度ダブルクリックすると降りてきます。

  1. Code タブの中で Local を選びます。

  2. Select folder を押して、いま作った ~/ai/mycompany を選びます。
  3. 送信ボタンの横のドロップダウンで、モデルを選びます。迷ったら、いちばん賢いものを選んでおけば大丈夫です。
  4. 下の文をコピーして、入力欄に貼って送ります。

これを送ると何が起きるか：数秒で、日本語の返事が10行ぶん流れます。それが動いた合図です。

👉 英語で返ってきた人だけ開く押して開く

  1. 「日本語で答えてください」と、そのまま1行送ります。
  2. 第2章でAI秘書の中身を置くと、毎回言わなくても日本語で返るようになります。

この先、AIがファイルを書こうとするたびに、「これでいい？」という確認が出ます。

2-1. CC-Booster を取ってきて広げる

CC-Booster は、圧縮ファイル1個です。中身を、第1章で作った ~/ai/mycompany に入れます。

  1. Safari で下のリンクを開きます。開いた瞬間にダウンロードが始まります。

    cc-booster-v1-release.zip をダウンロード（約16MB）

  2. Finder の「ダウンロード」にできた cc-booster-v1-release.zip をダブルクリックします。

    Mac は自動で中身を取り出してくれます。

  3. できたフォルダを開いて、中に CLAUDE.md というファイルが直接見えることを確かめます。
  4. 見えたら、その階層の中身をぜんぶ、さっき作った mycompany フォルダへドラッグして移します。
👉 CLAUDE.md が見あたらない人だけ開く押して開く

大丈夫です。もう1階層ふかいところに入っているだけです。

フォルダの中にフォルダが1つだけあったら、それを開いてください。CLAUDE.md が見える階層が、あなたの本当の中身です。その中身を mycompany へ移します。

👉 .claude というフォルダが見えない人だけ開く押して開く

大丈夫です。消えていません。Finder が隠しているだけです。

名前が「.」で始まるフォルダは、Finder では最初から見えません。Cmd + Shift + .（コマンド＋シフト＋ピリオド）を押すと見えます。もう一度押すと、また隠れます。

見えていなくても、ちゃんとコピーされています。この先、あなたがこのフォルダを開く用事はありません。AIが中を見るだけです。

👉 ダウンロードが途中で止まった・開けなかった人だけ開く押して開く

大丈夫です。もう一度やれば、たいてい通ります。約16MBあるので、回線が細いと途中で切れることがあります。

  1. まず、ブラウザでリンクをもう一度押します。落ちてきたファイルの大きさが16MBくらいあるか見てください。極端に小さければ、失敗しています。
  2. それでもダメなら、Wi-Fi を切り替えるか、しばらく置いてからやり直します。
  3. 広げたのに CLAUDE.md が出てこないときは、圧縮ファイルが壊れています。落としたファイルを捨てて、最初からやり直してください。

2-2. Claude にそのフォルダを開き直させる

中身が入ったので、Claude にもう一度そのフォルダを見せます。

  1. Claude の Code タブに戻ります。
  2. 新しいセッションを1本始めます。
  3. Local が選ばれていることを確かめて、Select folder から ~/ai/mycompany を選びます。

⚠️ ここで英語の窓が出ることがあります

CC-Booster には、開いたときに動く小さな仕掛けが入っています。そのため、初めてこのフォルダを開くと「このフォルダの設定を信用していい？」と聞かれることがあります。

This folder contains settings / hooks. Do you trust the authors of the files in this folder?

「このフォルダに入っている設定を、信用していい？」と聞かれています。

押すのは 信用する側（Yes / Trust） です。

自分でダウンロードして、自分で置いたものです。信じて大丈夫です。ここで断ると、AI秘書の安全のかこいが動きません。

窓の文言は、僕の手元では確かめられていません。見た目がちがっても、信用する側を押せば同じです。

2-3. 名前を付け替える作業は、ありません

🍀 ここが Codex 版といちばん違うところ

Codex というAIを使う場合、ここで CLAUDE.md を AGENTS.md という名前に付け替える作業が要ります。読んでくれるファイルの名前が違うからです。

Claude Code では、その作業はまるごと要りません。CLAUDE.md は、そのままの名前で、勝手に読まれます。何もしなくていいです。

2-4. ちゃんと読めたか、1行で確かめます

置いたつもりで置けていない、という事故がいちばん多いところです。目で見て確かめるより、AI に読ませて答えさせるほうが確実です。

これを送ると何が起きるか：1つめが「cc-booster のAI秘書」、2つめが .onboarding-status と返ってくれば、ちゃんと読めています。3つめは、ファイルの削除・秘密の情報・勝手な外部発信などが挙がるはずです。

👉 答えが違った・「そんなファイルはありません」と言われた人だけ開く押して開く

  1. Claude で開いているのが ~/ai/mycompany そのものか見ます。中のフォルダを開いていませんか。
  2. そのフォルダの直下に CLAUDE.md があるか見ます。1階層ふかいところに入っていたら、中身を上に出してください。
  3. 新しいセッションを始めて、もう一度送ります。
