CC-Booster 手順書一式
=====================================

このフォルダには、HTMLファイルが5つ入っています。
どれもダブルクリックすれば、ふだんお使いのブラウザで開きます。
インターネットにつながっていなくても読めます。


■ まず、これを開いてください

    index.html      ← ここから始めてください

「はじめる前の全体図」です。
ChatGPT・Gemini・Codex・Claude Code は何が違うのか、
料金はいくらかかるのか、AI秘書で何ができるのかを、
専門用語なしで10分で読めるようにまとめてあります。

このページのいちばん下から、自分に合った手順書へ進めます。


■ 手順書は4本あります（自分に合うものを1本だけ選びます）

    claude-code/mac.html        Claude Code を Mac で使う人
    claude-code/windows.html    Claude Code を Windows で使う人
    codex/mac.html              Codex を Mac で使う人
    codex/windows.html          Codex を Windows で使う人

どちらを選べばいいかは、index.html に書いてあります。
迷ったら、まず index.html を読んでください。


■ 使うときのコツ

・進み具合のチェックは、お使いのブラウザの中に残ります。
　途中で閉じても、次に開いたときに続きから案内します。
・右上の月のマークで、暗い配色に切り替えられます。
・印刷して紙で読むこともできます。
　ブラウザの印刷から「PDFとして保存」を選んでください。
　折りたたんである部分も、印刷すると全部開いた状態で出ます。


■ フォルダの形を変えないでください

ページどうしがつながっているので、
ファイルを別々の場所に移すとリンクが切れます。
このフォルダごと、まとめて置いてください。


■ 困ったときは

各手順書の中に「詰まったときの相談先」があります。
一人で30分粘るより、画面の写真を1枚送るほうが早いです。
